# Flow Design System

Flow Design System is a scalable React-based design system focused on accessibility, consistency, motion, and reusable UI foundations.

## Overview

This project was created to build a unified visual language for digital products.

The system includes:

- Foundation tokens
- Color palettes
- Typography
- Spacing system
- Grid system
- Button components
- Icon guidelines
- Motion interactions
- Accessibility guidelines

---

## Tech Stack

- React
- Tailwind CSS
- Vite
- GitHub Pages

### Foundation

Core visual foundations of the system.

Reusable UI components.

Motion guidelines and easing simulations.

### Advertising

Reserved for future ad and campaign guidelines.

## Accessibility

This system follows accessibility-first principles.

### Includes

- Keyboard navigation
- Screen reader support
- Contrast ratio guidance
- Color blindness considerations
- Touch target recommendations

---

## Design Principles

### Consistency

Maintain visual and interaction consistency across all products.

### Scalability

Designed to scale across multiple services and platforms.

### Accessibility

Components should be usable by everyone.

### Motion

Motion should support usability and hierarchy rather than decoration.
